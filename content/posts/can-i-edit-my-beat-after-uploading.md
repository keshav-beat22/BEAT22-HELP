Once you’ve uploaded your beat on Beat22, you can make changes to <strong>some parts but not everything.</strong>
<h3><strong>What you <em>can</em> edit:</strong></h3>
<ul>
 	<li><strong>Metadata</strong> (Beat Title, Genre, Mood, BPM, Tags, etc.)</li>
 	<li><strong>License</strong> <strong>settings</strong> (Prices, Terms, License types)</li>
</ul>
<h3><strong>What you <em>can’t</em> edit:</strong></h3>
<ul>
 	<li><strong>Tagged MP3 file</strong></li>
 	<li><strong>Untagged WAV file</strong></li>
 	<li><strong>WAV + Stems zip file</strong></li>
 	<li><strong>Cover Art</strong></li>
</ul>
<h2><strong>Want to change media files?</strong></h2>
If you need to update any of the media files (audio or artwork), you’ll need to:
<ol>
 	<li>Delete the current beat</li>
 	<li>Re-upload it from scratch, filling out all metadata and license info again</li>
</ol>
<h4><em><strong>Pro Tip:</strong> Double-check all media before uploading to save time later!</em></h4>
