<h3><b><span data-contrast="none">1. Labeling Your Samples</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none">To maintain professionalism and ensure smooth uploads, your sample files must follow this exact naming format:</span>

<span data-contrast="none">SampleName_BPM_Key_YourName_[CollaboratorName].wav</span>

<span data-contrast="none">Example (solo): MidnightGlow_140BPM_Cmin_ProdByK28.wav</span>
<span data-contrast="none">Example <strong>(with collaborator)</strong>: Stars_98BPM_Bminor_ProdByJai_<strong>ProdbyK28</strong>.wav</span>

<span data-contrast="none">(a) Use “ProdBy” before your name.</span>
<span data-contrast="none">(b) Use underscores to separate each element.</span>
<span data-contrast="none">(c) Do not use spaces or skip elements.</span>

<span data-contrast="none">Must include:</span>
<span data-contrast="none">- Sample Name (clean and creative)</span>
<span data-contrast="none">- BPM (tempo, e.g., 98, 140BPM)</span>
<span data-contrast="none">- Key (e.g., Cmin, F#maj, Bminor)</span>
<span data-contrast="none">- Your Name (with ProdBy)</span>
<span data-contrast="none">- Collaborator(s), if any</span>

<span data-contrast="none">Mandatory Format - Files not labeled correctly will be rejected.</span><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;201341983&quot;:0,&quot;335559738&quot;:0,&quot;335559739&quot;:200,&quot;335559740&quot;:276}"> </span>
<h3><b><span data-contrast="none">2. Tags</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none"> Tags improve discoverability. Use tags related to:</span>

<span data-contrast="none">- Genre: trap, drill, R&amp;B, etc.</span>
<span data-contrast="none">- Instrument: piano, flute, guitar, synth</span>
<span data-contrast="none">- Mood/Vibe: dark, dreamy, ambient</span>
<span data-contrast="none">- Influence: Travis Scott, Cubeatz, etc.</span>

<span data-contrast="none">Don’t over-tag. Keep it focused and specific.</span><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;201341983&quot;:0,&quot;335559738&quot;:0,&quot;335559739&quot;:200,&quot;335559740&quot;:276}"> </span>
<h3><b><span data-contrast="none">3. Collaborators (feature coming soon)</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none">If working with others:</span>
<span data-contrast="none">- Add their names to the filename: Stars_98BPM_Bminor_ProdByXYZ_</span><span data-contrast="none">Prod.Mxrci</span><span data-contrast="none">.wav</span>
<span data-contrast="none">- Ensure all collaborators approve the upload</span>

<h3><b><span data-contrast="none">4. Outside Loops</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none">Do NOT use:</span>
<span data-contrast="none">- Splice, Cymatics, Looperman loops</span>
<span data-contrast="none">- Loops from kits you don’t own</span>
<span data-contrast="none">- Royalty-free packs you didn’t make</span>

<span data-contrast="none">Only upload 100% original content.</span>

<span data-contrast="none">Any violation may result in removal of the pack.</span><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;201341983&quot;:0,&quot;335559738&quot;:0,&quot;335559739&quot;:200,&quot;335559740&quot;:276}"> </span>

<h3><b><span data-contrast="none">9. Stems</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none">Option 1: Separate Files (Preferred)</span>
<span data-contrast="none">- Export all instruments individually</span>
<span data-contrast="none">- All stems should start from bar 1</span>
<span data-contrast="none">- Name clearly: Piano.wav, Drums.wav</span>

<span data-contrast="none">Option 2: Combined Single File</span>
<span data-contrast="none">- Play all parts one after another</span>
<span data-contrast="none">- Attach a ReadMe.txt or visual guide</span>
<span data-contrast="none">- File name: Loop1_StemsCombined.wav</span>

<span data-contrast="none">Attach a short tutorial (inside Tutorials/ folder or via link)</span><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;201341983&quot;:0,&quot;335559738&quot;:0,&quot;335559739&quot;:200,&quot;335559740&quot;:276}"> </span>

<h3><b><span data-contrast="none">11. Licensing, Publishing &amp; Splits</span></b><span data-ccp-props="{&quot;134233117&quot;:false,&quot;134233118&quot;:false,&quot;134245418&quot;:true,&quot;134245529&quot;:true,&quot;201341983&quot;:0,&quot;335559738&quot;:200,&quot;335559739&quot;:0,&quot;335559740&quot;:276}"> </span></h3>
<span data-contrast="none">Licensing Fee</span>
<span data-contrast="none">- Buyers get non-exclusive, royalty-free use, unless you specify otherwise</span>
<span data-contrast="none">- No upfront fee charged by Beat22</span>
<span data-contrast="none">- You can also sell kits elsewhere (unless exclusive)</span>

<span data-contrast="none">Publishing Rights</span>
<span data-contrast="none">If your loop is used in a major/label release:</span>
<span data-contrast="none">- You’re entitled to publishing/master splits</span>
<span data-contrast="none">- You must handle negotiation directly with buyer</span>

<span data-contrast="none">Optional: Dynamic Splits</span>
<span data-contrast="none">If opted-in and used in a 1M+ stream track:</span>
<span data-contrast="none">- Up to 25% publishing split (full use)</span>
<span data-contrast="none">- 12.5% for partial usage</span>

<span data-contrast="none">Applies only when buyer is a Beat22 user.</span>
